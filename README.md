 Fri 15 May 17:16:23 PDT 2026

This is the source repository for building cdpw which is
the add on software to a Debian 13 based system that
will run Orthanc for the Code Dark PACS Workstation project
at Kaiser, Northern California.

Documentation over what Code Dark is may be found under
the Documentation directory or other places as noted
below.

This source can built under Ubuntu or Debian and a
bootable USB key can be made from it. Instructions
for making the key is also under Documentation.

Code DARK PACS Workstation (cdpw) no long requires an additional
USB storage device which was a secure APRICORN device which has a key
pad to unlock. Now, when officially deployed, the entire Apricorn
device will be the (only) device to be used (and booted from). This
will contain patient data which needs te proteccted.

For build instructions- see the file called 'BUILD' in this directory.
