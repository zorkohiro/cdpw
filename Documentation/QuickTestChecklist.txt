Version 0.6

This a quick checklist to check a Code Dark release for sanity.

1. Booting

Does it boot correctly to the USB key when you have the USB key inserted?

If it does not, you may have to enter the BIOS to change configurations
to be able to boot the USB key, either automatically or being able
to hit escape key for that system and boot if from a boot menu. This
is not necessarily a test of cdpw- this is a test of correct hardware
configuration. You may also need to disable secure boot.

Booting correctly means booting and being presented with a login screen.
You should be able to log in with user orthanc, password orthanc.

2. Multiple extended monitors and monitor resolution

Attaching more than one monitor (preferably before booting) should yield
multiple separately accessible screens. The monitors should be displaying
at the expected pixel density.

You should be able to right click the mouse on the desktop to be able
configure the display about what the Wayland server thinks about monitor
placement (e.g. right to left) and monitor orientation (for monitors
that flip).

Test further by opening things like Konsole or the Firefox browswer
and drag them across monitor boundaries.

Any artifacts like the monitor(s) freezing when moving windows around
across edge boundarie, or any freezing of obviously incorect video
artifacts, indicate a problem that must be resolved in development.

3. Finding out if Orthanc is running.

Once logged in, you should be able to upon the FireFox web browser
(firefox icon, bottom bar, extreme left). Skipping past any restore
connections pages nonsense, you should see a bookmark in the upper
right. You should select that (which selects http://localhost:8042)
and that should get you the initial Orthanc front page (which is
used for study or patient selection).


4. Setting Network Configuration (Linux desktop)

After logging in, you should be able to navigate to Settings icon on
the bottom taskbar (it looks like a gear wheel). Click on that and
somewhere at the top of the window that opens will be the Network
selection. Click and that and use Help and Documentation and your
specific site settings to configure networking appropriately.

Typically this will be a static IP address and netmask so that
the various modalities which are hard to actually change can
talk to you just as if you were their normal DICOM server.


5. Setting System Time

Since we cannot depend upon a network time server, you need to
set the time correctly (reports created and reviewed need the
correct date and time).

Use the Settings window and use the search (magnifying glass)
icon to search for "Time" to select Date and Time. You will
need to unlock it to make changes- this will put up a window
asking for the Administrator privilege password (same as the
orthanc login password).

5. Setting Code Dark specific DICOM and other parameters

Find the "code dark configurator" icon on the desktop and select
that to fire up that tool.

5a) Enter AET and DICOM Port Parameters

Change the AET and DICOM Port Parameters to be what things that the
local modalties require.

5b) Edit or add to the authorized physician list

There is an edit box of doctors, separated by a ',' (comma) that you can edit.

5c) Save and Exit

SAVE AND EXIT button will give you an alert button that a reboot may
be required for this to become active. This may not be necessary if
this is the only operation you are doing at this time.


6. Receipt of studies from a remove system

Once you have set network, AET and DICOM paramaters, you should be able to
receive studies from the remote system.

Once it is claimed they are there, you should be able to search for them with
a local browser pointing to Orthanc (http://localhost:8042)

7. Use the Code Dark Study Tool to look for studies to review, sign and print.

You can click on the icon on the desktop "Code Dark Study Tool". This will bring
up a top menu listing actions you can take which will bring up subordinate menus.

This is a simplistic workflow manage.

When you do a review, a browser window for that study will be opened up within
Orthanc. One of the buttons to the side allows you to fire up the OHIF Viewer
to do the actual review of the studies. A review also brings up (for the
first time) a list of possible study templates to choose from and then
a report window for the review.

8. Configure and Test a Printer

Follow Ubuntu 24.04 documentation for finding a configuring a printer if you have
one attached (or findable on the net, although that only should be true
in test environments). Test the printer by printing a test page.

9. Print a Report

Navigate back to the code_dark_studytool window and print a signed report
and see whether it prints on the printer.
