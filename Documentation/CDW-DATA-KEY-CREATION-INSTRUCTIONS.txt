DATA KEY CREATION, version 3

These are the instructions for creating the data storage
device for the CDPW workstation.

It is intended for the Apricorn secure storage device, but can be,
for testing purposes, applied to any USB storage device.

1. Requirements

A 2GB or better USB device- USB 3.1 or newer.
A PC running Windows 10 or Windows 11.

2. Format

Insert the device into the PC (and unlock it with the keypad if it is an Apricorn).
Format it via the Explorer:

 + Select NTFS type
 + Add CODE_DARK as the filesystem/volume label.

=====================================================================

Users who want to do this under linux- feel free. Instructions not
offered because if you want to do this under linux, we assume you
are experienced enough to know what you want to be doing.

We selected NTFS as the type as interchange with Windows systems.
It will be mounted such that only the user orthanc under linux
can access data.
