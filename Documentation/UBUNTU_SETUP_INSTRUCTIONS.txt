0. Required Hardware and Environment

Get a USB flash drive of at least 16GB to put the ubuntu install image on.

Get a USB flash drive of at lesat 32GB to become the target of the install.

You can certainly user an even larger USB Key for the target of the install-
but this just makes it more painful when copying the gold master to multiple keys
for distribution. The effective size requirements are an overgenerous ~17GB
currently.

You will need to be connected to the internet to perform the following steps.

1. Copy Ubuntu 24.04.4 live server from the iso image to the USB install image from
an ubuntu mirror, e.g.:

 https://mirror.fcix.net/ubuntu-releases/24.04.4/ubuntu-24.04.4-live-server-amd64.iso
 sha256sum: e907d92eeec9df64163a7e454cbc8d7755e8ddc7ed42f99dbc80c40f1a138433

If the above URL does not work (and over time this is likely to happen),
a cached version may be found under: https://feralsw.com/cdpw/isos.

Create the Install USB key from this with dd on a linux system or Rufus on a Windows system.

2. Create a Bootable Gold Image CDPW System

Take the install key to any reasonable recent x86_64 system and insert it. Make sure it is
enabled for UEFI booting (not Legacy boot).

Power and and boot the install key (you'll have to hit F8 or F11 to get a 'boot from' menu
to boot that install key- this is vendor and even model specific). It will be a UEFI boot.

Once up, the installation starts automatically. It is a curses/text based install- not
a GUI based installer.

The first step prior to continuing with the installation which is waiting for input
at the first step is to insert the USB which will become the target of the install
(the new Gold Master).

You'll have to play around with navigating this installer or read documentation on
the Ubuntu Canonical website but it's pretty uncomplicated and nearly always you
can take the default answer.

As you navigate through the install, here are a couple of notes to guide you where
the answer needs to be supplied or the default is not desired.

 + Do not update to a new installer (as offered by the installer)

 + Setting up the target installation media is tricky and you need to get it right:
   o Don't pick "default" installation target. There are steps (in the future) that will
     not be able to be accomplshed if you do that.
   o Select an alternate disk and go through the edit steps there to accomplish the following:
     = Select the USB device that is to be the Gold Master as the "Boot device"
     = Create a 16G new partition on the otherwise blank Gold Master- if there are old partitions
       on that device because you are reusing something old, delete them all first.
     = Create a 16GB partition on the install target and leave it "unformatted".
     = Create a volume group on top of this partition
     = Create a logical volume of 12GB on top of this voluem group. This gets marked as to be
       created with an ext4 filesystem and mounted on /.
     = The installer will automatically create a UEFI boot partition for you.

  + User creation:

    Select 'Saruman B Orthanc' as the user name.
    Select 'orthanc' as the name of the system.
    Select 'orthanc' as the user, 'orthanc' as the password.

When the installation is done, reboot to gold master USB key.
During the reboot process it will ask you to remove the installation USB key.

It will come up with a standard text based linux screen (i.e., just a text
"login: " message. You can log in with orthanc/orthanc.

3. Upgrade the kernel to the one with admgpu fixes for Barco adapters.


#
# Upgrade kernel with updated amdgpu driver.
#
Upgrade the kernel packages to get the amdgpu driver fixes for multiple monitors.
See the build instructions under kernel. This should already have been done
for you on another system.

The modules you are interested in capturing out of the entire build will be something like:

linux-image-unsigned-6.14.0-1030-generic_6.14.0-1030.32~24.04.1_amd64.deb
linux-modules-extra-6.14.0-1030-generic_6.14.0-1030.32~24.04.1_amd64.deb
linux-modules-6.14.0-1030-generic_6.14.0-1030.32~24.04.1_amd64.deb

Fetch the updated kernel and drivers that have been already built for you like so:

 rm -rf /var/tmp/kupdate
 mkdir -p /var/tmp/kupdate
 cd /var/tmp/kupdate
 wget https://feralsw.com/cdpw/1030_upgrade.tar
 tar xf 1030_upgrade.tar
 sudo apt install -y /var/tmp/kupdate/*.deb
 cd /var/tmp
 rm -rf /var/tmp/kupdate

Reboot after they have installed. This should get you into a system
with fixes to support the special Barco adapters used at Kaiser under Windows.
Use 'uname -r' after a reboot and logging in. The kernel major version should be 6.14
instead of the standard 6.8 for Ubuntu 24.04 LTS.

4. Install a ubuntu desktop (graphics environment)

After rebooting and logging in, become super-user
with

  sudo su -

which will ask you for a password (orthanc's password).

Do the following:

   + apt update -y
   + apt install -y software-properties-common
   + apt install -y ubuntu-desktop-minimal

Go out and get a cup of coffee or lunch since about 900 packages
will have to be downloaded and installed.

When done, reboot. You should be presented with an ubuntu
graphical login screen.


5. Install our CDPW packages

Fetch the latest set of installable cdpw user packages with this command:

 rm -rf /var/tmp/packages
 cd /var/tmp/packages
 wget https://feralsw.com/cdpw/cdpw-latest.tar
 tar xf cdpw-latest.tar
 sudo apt install -y /var/tmp/packages/*.deb
 cd ..
 rm -rf packages

Ignore and dismiss all alert boxes or popups that may show up during this.

Find where code_dark_configurator and code_dark_study_tool and 'about code dark' icons
been put onto the desktop. Do a pull right menu over them if they have a little red 'x'
and select the "Allow Launch" option. This is an unfortunate aspect of Gnome3 that doesn't
allow one to do this programmatically at installation time.

6. System Control panel changes

Go to system settings under the system menu.

Go to Ubuntu Desktop and shrink the taskbar icons and place the taskbar
on the bottom of the screen. Disable Home Folder on desktop.
Unpin 'A' window and help icons from taskbar on botton.

Search for Date & Time and disable automatic date and time.

Search for Privacy & Security
 Set under Screen Lock:
	+ 10 minutes blank screen delay
	+ Automatic Screen Lock ON
	+ Automatic Screen Lock delay 1 minute
	+ Lock Screen notifications ON
	+ Lock Screen on Suspend ON

Fire up a Kconsole and pin it to the task bar

Right click on Desktop and select under arranged 'Keep arranged'.

#
# Set background to plain gray
#
gsettings set org.gnome.desktop.background picture-uri none
gsettings set org.gnome.desktop.background primary-color gray

#
# Disable automatic updates && upgrades
#
sudo dpkg-reconfigure -plow unattended-upgrades
sudo systemctl disable apt-daily.timer
sudo systemctl disable apt-daily-upgrade.timer
sudo apt remove --purge -y unattended-upgrades
sudo apt remove --purge -y update-notifier


6. Configure the installed firefox

Remove crap buttons from bookmark bar
Settings/General
 Unclick "Open links in new tabs instead of new windows"
Settings/Home
 Set both Homepage and new tabs as blank page
 Uncheck Shortcuts Recommended Stories 

Enter about:config in address bar
Say yes to continuing and taking the risk
In the search bar enter sessionstore.
For browser.sessionstore.resume_from_crash- set to false.
For browser.sessionstore.max_resumed_crashes- set to 0.

Enter http://localhost:8042 in chrome and bookmark it. You should
have connected with the running orthanc server.

7. Install gdm-settings and set up new login screen with a Kaiser label

Get a Kconsole up and issue:

sudo apt install gdm-settings libglib2.0-dev-bin

Look under the Apps panel for the GDM-SETTINGS icon and fire it up.

Under Login Screen add /usr/share/cdpw/code_dark_label_nv.gif as the image.
You'll have to use ls to see what the latest label is.

Under Appearance/Background change type to image and add
/usr/lib/cdpw/KaiserRedSmall.png as the image.

Hit the apply Button when done here to persist the changes.
You will likely have to enter the password for user orthanc.
