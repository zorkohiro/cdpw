0. Required Hardware and Environment

Get a  8GB USB flash drive to put the ubuntu install image on.

Get a 16GB USB Key to become the target of the install. You
can certainly user a larger USB Key for the target of the install-
but this just makes it more painful when copying the gold master
to multiple keys for distribution.

You will need to be connected to the internet to perform the following
steps- but note that some careful steps need to be followed so as to
not make randomly different base images due to the aggressive attempts
by the ubuntu installer to update the latest sets of images.

1. Copy Ubuntu 24.04.3 from the iso image, e.g.:

 https://releases.ubuntu.com/noble/ubuntu-24.04.3-desktop-amd64.iso
 sha256sum: faabcf33ae53976d2b8207a001ff32f4e5daae013505ac7188c9ea63988f8328

Create the 8GB Install USB key from this with dd on a linux system or
rufus on a Windows system.

2. Create a Bootable Gold Image CDPW System

Take the install key to any reasonable x86_64 system. Insert both it and the
16GB USB Key you are going to use as the Gold image into the system.

Boot the install key (you'll have to hit F8 or F11 to get a 'boot from' menu
to boot that install key).

Once up, you should be able to start installation.


Select 'Saruman B Orthanc' as the user name.
Select 'orthanc' as the name of the system.
Select 'orthanc' as the user, 'orthanc' as the password.

Select the defaults and erase the whole disk and install to it.
Make sure that is installing to the 16GB USB Gold Key

Keep selection to require user password to log in.

Set the timezone you are in. If you booted up with an active internet connection it
should have made a good guess already.

When the installation is done, reboot to gold master USB key. During the reboot
process it will ask you to remove the installation USB key.

2. Upgrade the kernel

#
# Upgrade kernel with updated amdgpu driver.
#
Upgrade the kernel packages to get the amdgpu driver fixes for multiple monitors.
See the build instructions under kernel. This should already have been done
for you on another system.

The modules you are interested in capturing out of the entire build will be something like:

linux-image-unsigned-6.14.0-32-generic_6.14.0-32.32~24.04.1_amd64.deb
linux-modules-6.14.0-32-generic_6.14.0-32.32~24.04.1_amd64.deb
linux-modules-extra-6.14.0-32-generic_6.14.0-32.32~24.04.1_amd64.deb

Fetch the updated kernel and drivers that have been already built for you like so:

 mkdir -p /dev/shm/kupdate
 cd /dev/shm/kupdate
 wget https://feralsw.com/cdpw/1020_upgrade.tar
 tar xf 1020_upgrade.tar
 sudo apt install -y /dev/shm/kupdate/*.deb

Reboot after they have installed. This should get you into a system
with fixes to support the special Barco adapters used at Kaiser under Windows.

3. Install our CDPW packages

After we come up with the new kernel and driver, do

 sudo apt update

This will refresh our package lists and make sure we have an up to
date network IP address for the Ubuntu package repositories.

Fetch our latest set of installable packages with this command:

 cd /var/tmp
 wget https://feralsw.com/cdpw/cdpw-latest.tar
 rm -f *.deb
 tar -xf cdpw-latest.tar
 sudo apt install -y /var/tmp/*.deb

Ignore and dismiss all alert boxes that may show up before things finish.

As you continue along delete any popups asking to install updates.

Find where code_dark_configurator and code_dark_study_tool icons got put onto the desktop.
Do a pull right menu over them if they have a little red 'x' and select the "Allow Launch"
option. This is an unfortunate aspect of Gnome3 that doesn't allow one to do this
programmatically at installation time.

4. System Control panel changes

Go to system settings under the system menu.

Go to Ubuntu Desktop and shrink the taskbar icons and place the taskbar
on the bottom of the screen. Disable Home Folder on desktop.
Unpin 'A' window and help icons from taskbar on botton.

Search for Date & Time and disable automatic date and time.

Search for Privacy & Security
 Set under Screen Lock:
	+ 10 minutes blank screen delay
	+ Automatic Screen Lock ON
	+ Automatic Screen Lock delay 1 minute
	+ Lock Screen notifications ON
	+ Lock Screen on Suspend ON

 Set under Diagnostics:
	+ Send error reports to Canonical to NEVER

Fire up a Kconsole and pin it to the task bar

Right click on Desktop and select under arranged 'Keep arranged'.

#
# Set background to plain gray
#
gsettings set org.gnome.desktop.background picture-uri none
gsettings set org.gnome.desktop.background primary-color gray

#
# Disable automatic updates && upgrades
#
sudo dpkg-reconfigure -plow unattended-upgrades
sudo systemctl disable apt-daily.timer
sudo systemctl disable apt-daily-upgrade.timer
sudo apt remove --purge -y unattended-upgrades
sudo apt remove --purge -y update-notifier


5. Configure the installed firefox

Remove crap buttons from bookmark bar
Settings/General
 Unclick "Open links in new tabs instead of new windows"
Settings/Home
 Set both Homepage and new tabs as blank page
 Uncheck Shortcuts Recommended Stories 

Enter about:config in address bar
Say yes to continuing and taking the risk
In the search bar enter sessionstore.
For browser.sessionstore.resume_from_crash- set to false.
For browser.sessionstore.max_resumed_crashes- set to 0.

Enter http://localhost:8042 in chrome and bookmark it. You should
have connected with the running orthanc server.

6. Install gdm-settings and set up new login screen with label

Get a Kconsole up and issue:

sudo apt install gdm-settings libglib2.0-dev-bin

Look under the Apps panel for the GDM-SETTINGS icon and fire it up.

Under Login Screen add /usr/lib/cdpw/code_dark_label_nv.gif as the image.
You'll have to use ls to see what the latest label is.

Under Appearance change type to image and add /usr/lib/cdpw/KaiserRedSmall.png as the image.
Hit the apply Button. You will likely have to enter the password for user orthanc.
